# Installation
```bash
omarchy-theme-set https://github.com/lensku-dev/Arch-Dark.git
```

# Installation for screensaver and fastfetch logo
```bash
chmod +x ~/.config/omarchy/themes/arch-dark/install.sh
```
```bash
cd ~/.config/omarchy/themes/arch-dark/
```
```bash
./install.sh
```
